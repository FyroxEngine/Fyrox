# Noto Sans SC

This directory contains **Noto Sans SC** from the official Google Fonts
repository:

https://github.com/google/fonts/tree/main/ofl/notosanssc

The font is distributed under the SIL Open Font License 1.1. The complete
license text is included in `OFL.txt`. The variable font file is
`NotoSansSC[wght].ttf`.
